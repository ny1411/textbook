# Geist fonts

Unmodified variable WOFF2 fonts from the official `geist` npm package, version
1.7.2 (https://www.npmjs.com/package/geist). The bundled SIL Open Font License
is preserved in `LICENSE.txt`.

`next/font/local` serves these assets using the existing Geist CSS variables.
Production builds do not need to download fonts from Google.
