## Skiper UI

The measured spring caret in `components/ui/smooth-input.tsx` is adapted from **[Skiper UI / gxuri — Smooth Caret Input (Skiper106)](https://skiper-ui.com/v1/skiper106)**. Credit and attribution belong to Skiper UI / gxuri. The component page permits personal and commercial use/modification and requires attribution for the free version. This notice and the source comment preserve that attribution. Textbook extends the effect for multiline text and provides native caret fallbacks for IME, RTL/bidi, touch, high contrast, and reduced motion; demo controls are omitted.

Paper Shaders, Motion, Radix, Lucide, and react-dropzone are consumed as package dependencies. Their upstream licenses/notices remain in the distributed packages. Source/documentation URLs are included in the component inventory.
